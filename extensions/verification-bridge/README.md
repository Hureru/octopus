# Octopus 验证桥

用于持久配对 Octopus，并在通过 Cloudflare 验证的真实浏览器标签页中执行站点同步或签到请求的 Manifest V3 扩展。

## 加载扩展

1. 打开浏览器的扩展管理页面。
2. 启用开发者模式。
3. 选择“加载已解压的扩展程序”，并加载本目录。
4. 在 Octopus 中为指定站点账号创建配对，然后在扩展中添加 Octopus 地址和一次性显示的配对令牌。
5. 配对保存后会显示设备、站点和账号。扩展重启后不需要再次输入。

## 使用流程

1. Octopus 遇到 Cloudflare 后会为已配对账号创建验证任务。
2. 扩展后台自动领取任务，并打开或复用目标站点窗口。
3. 如果 Cloudflare 要求人工确认，请直接在该窗口完成验证；扩展会识别站点正文恢复并自动继续。
4. 扩展在目标标签页中执行 Octopus 请求，直到同步或签到成功/失败。

弹窗关闭后，后台 Service Worker 仍会自动处理新任务。扩展需要访问配对站点，才能在目标页面主世界中使用浏览器自身的 Cookie、TLS 指纹和网络环境；请求仍被限制在任务目标 origin，Octopus 不会接收浏览器 Cookie。

弹窗中的领取、打开、执行和释放按钮作为故障恢复控制保留，正常情况下不需要手动操作。

如果浏览器重启时任务领取凭据已经过期或被服务端释放，扩展会自动清理旧状态并允许重新领取；如果服务端已经接受“验证完成”但响应在途中丢失，扩展会恢复正在执行的任务。

配对令牌保存在扩展本地存储中，只会发送到对应 Octopus 实例。扩展数据丢失时，请在 Octopus 管理端轮换该配对令牌，再用新令牌重新添加；旧令牌会立即失效。
